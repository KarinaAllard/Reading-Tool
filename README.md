#Reading Tool

A simple reading tool for personal use. During my studies, I read a lot of scientific articles and course material, and felt the need for an RSVP-like application that would allow me to read more quickly with less friction.

The text is processed locally in the browser and is not uploaded to or stored in a database. This allows me to use the tool with course material and other texts without having to upload the content to a third-party service.
